// QUEST  none, gold, boss or monsters      what your quest needs before it can be finished:

// START  four line numbers: where the talk opens when the quest is
//            not started,  started but not ready,  ready to finish,  done
//
// Then the lines, numbered 0, 1, 2 with no gaps. Each one is:
//     LINE 0
//     SAY what they say
//     A the first answer -> the line it leads to          (-1 ends the talk)
//     B the second answer -> the line it leads to         (B is optional)
//     GIVES what happens when this line is reached        (optional)
// A line with nothing to choose has NEXT in place of A and B, and must lead forwards or to -1:
//     NEXT 3
//
// What a line can give:
//     give potion   give arrows   give stones   give shield   give gold
//     heal party   restore mana   power might   power guard   power regen
//     start quest   finish quest
